## ApiLens v0.10.0 — Spring Boot 4.1 판올림 · agent 안 Jackson 고침판 | Spring Boot 4.1 upgrade and a patched Jackson inside the agent

**collector(server)를 Spring Boot 4.1 로 올린 판입니다.** 서버가 쓰는 Spring Framework 7.0 · Tomcat 11.0 · Hibernate 7.4 ·
Flyway 12.4 · SQLite 드라이버 3.53.4.0 이 모두 새 지원 라인입니다. **agent 도 다시 배포하세요** — agent 코드는 그대로지만
안에 든 Jackson 이 2.18.12 로 바뀌었고, 새 agent jar 로 바꾸고 대상 앱을 재시작해야 그 고침이 대상 앱에 닿습니다.
다시 배포하지 않은 agent 도 새 collector 로 그대로 보낼 수 있습니다.

**DB 스키마는 바뀌지 않습니다** — 마이그레이션이 없어, 되돌리려면 이전 jar 로 바꾸기만 하면 됩니다. **하위호환을 깨는
변경도 없습니다.** 화면 왼쪽 위 버전 라벨이 **`v0.10`** 으로 바뀝니다.

**This release moves the collector (server) to Spring Boot 4.1** — Spring Framework 7.0, Tomcat 11.0, Hibernate 7.4,
Flyway 12.4 and the SQLite driver 3.53.4.0 are all on supported lines now. **Please redeploy the agent as well**: its
code is unchanged, but the Jackson bundled inside it is now 2.18.12, and the fix only reaches your application after you
swap in the new agent jar and restart the application. Agents you have not redeployed keep sending to the new collector.
**No database migration and no breaking change** — rolling back is just swapping the jar. The version label in the
top-left corner becomes **`v0.10`**.

### 바뀐 것 | Changed

- **서버 지원 라인 전환.** Spring Boot 4.1.2 · Spring Framework 7.0 · Tomcat 11.0 · Hibernate 7.4 · Flyway 12.4 ·
  SQLite 드라이버 3.53.4.0 · springdoc 3.2. API 경로 · 요청 · 응답 모양은 그대로이고, `/v3/api-docs` 문서도 OpenAPI 3.0
  꼴 그대로입니다.
- **서버 JSON 처리는 Jackson 3 가 맡습니다.** 마스킹 엔진만 agent 와 같은 Jackson 2 를 써서, 서버와 agent 의 마스킹 결과가
  같습니다(서버 안에서 두 판이 함께 있습니다).
- **실패 모드 변경.** `POST /v1/spans` 본문이 숫자 칸에 `null` 을 넣었거나 올바른 JSON 뒤에 글자가 더 붙어 있으면, 전에는
  `202` 로 받았지만 이제 `400` 으로 거절합니다. agent 는 이런 본문을 만들지 않습니다.
- **수집기를 Java 21 ~ 27 에서 띄울 수 있습니다.** 컴파일 대상은 Java 21 그대로입니다.
- **agent 안의 Jackson 을 2.18.12 로 올렸습니다**(relocate 된 채 들어 있어 대상 앱의 Jackson 과 부딪히지 않습니다).
- **빌드 도구** — Gradle wrapper 를 8.14 로 올렸습니다. Gradle 9 는 agent jar 안 구성이 달라지는 문제가 있어 이번에는
  올리지 않았습니다.

- **Server support lines.** Spring Boot 4.1.2, Spring Framework 7.0, Tomcat 11.0, Hibernate 7.4, Flyway 12.4, SQLite
  driver 3.53.4.0, springdoc 3.2. API paths, requests and response shapes are unchanged; `/v3/api-docs` stays OpenAPI 3.0.
- **Server-side JSON now runs on Jackson 3.** Only the masking engine keeps the same Jackson 2 the agent uses, so masking
  results stay identical between server and agent.
- **Failure-mode change.** A `POST /v1/spans` body with `null` in a numeric field, or with extra characters after valid
  JSON, used to be accepted with `202`; it is now rejected with `400`. The agent never produces such bodies.
- **The collector runs on Java 21 to 27.** The compile target stays Java 21.
- **Jackson inside the agent is now 2.18.12** (still relocated, so it never clashes with your application's Jackson).
- **Build tooling** — the Gradle wrapper moves to 8.14. Gradle 9 is held back because it changes the layout inside the
  agent jar.

### 보안 | Security

- 이번 판올림으로 Spring Framework · Spring Boot · Tomcat · Jackson · SQLite · logback 의 공지된 취약점 고침판 위로
  올라갔습니다. 공지별 영향 범위 · 고침판 · 이 제품에서의 성립 조건은 [`docs/security.md`](../docs/security.md) 에
  있습니다. 대조한 공지 가운데 이 제품에서 성립 조건이 갖춰진 것은 없었습니다.
- This upgrade puts the collector and agent above the fixed versions for the published Spring Framework, Spring Boot,
  Tomcat, Jackson, SQLite and logback advisories. See [`docs/security.md`](../docs/security.md) for the ranges, fixed
  versions and whether each condition applies to ApiLens — none of the checked advisories applies.

### 올리는 법 | Upgrade

1. collector 를 멈추고 `apilens-server-0.10.0.jar` 로 바꿔 다시 띄웁니다. 기동할 때 새 agent jar 가 `~/.apilens/` 에 풀립니다.
2. 대상 앱의 `-javaagent:` 가 가리키는 agent jar 를 새 것으로 바꾸고 대상 앱을 재시작합니다.

1. Stop the collector, replace it with `apilens-server-0.10.0.jar`, and start it again. On start it extracts the new
   agent jar into `~/.apilens/`.
2. Point your application's `-javaagent:` at the new agent jar and restart the application.
