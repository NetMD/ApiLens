## ApiLens v0.3.1 — 유지보수 모드(수신 일시정지) | Maintenance Mode (pause ingest)

디스크 최적화(VACUUM)·정리를 SQLite 잠금 경합 없이 끝내도록 **collector 의 적재만 잠시 멈추는**
유지보수 모드를 추가했습니다. 운영 중인 서비스는 멈추지 않고 collector 쪽 수신만 일시 차단합니다.
**server 와 UI 만 바뀌고 agent·common 모듈은 변경 없음** — v0.1~v0.3.0 agent 그대로 호환됩니다.

A maintenance mode that briefly **pauses only the collector's ingest** so disk optimization (VACUUM)
and cleanup finish without SQLite write-lock contention — your monitored services keep running.
**Only server and UI changed; the agent and common modules are unchanged** (fully compatible with
v0.1–v0.3.0 agents).

---

### 새로운 기능 | What's new

- **유지보수 모드 (수신 일시정지)** — 설정 페이지 "데이터 관리" 섹션의 [수신 일시정지]/[수신 재개] 버튼으로 collector 의 적재를 잠시 끊고, 디스크 최적화(VACUUM)·정리(purge/cleanup)를 잠금 경합 없이 수행합니다.
- **수신 일시정지 API 3종** — `GET /v1/maintenance/status` · `POST /v1/maintenance/pause` · `POST /v1/maintenance/resume`. 모두 `{ paused, pausedAt }` 를 반환하고 멱등하며, `/v1/**` 인증(키 설정 시 토큰)을 자동 계승합니다.
- **`POST /v1/spans` 503 응답** — 일시정지 중에는 `503 Service Unavailable` + `Retry-After: 60` 으로 응답하고 적재를 건너뜁니다(들어온 trace 는 저장되지 않음).
- **max-pause cap (30분 자동 재개)** — 일시정지를 켜둔 채 잊어도 30분 뒤 server 가 자동으로 수신을 재개합니다(안전장치).
- **유지보수 모드 UI** — 화면 상단 배너 · Services 화면 배지 · 일시정지 중 대시보드 실시간 갱신 자동 중단 · 정리 전 일시정지 권장 안내.

### 업그레이드 | Upgrade

- collector(server) jar 만 0.3.1 로 교체하고 재기동하면 됩니다. **agent jar 재배포 불필요** (agent 무변경).
- 상태는 in-memory 라 server 재시작 시 항상 수신 중(`paused=false`)으로 복귀합니다. **스키마 변경 0** — 0.3.0 DB 와 그대로 호환되고, 0.3.0 으로 롤백해도 데이터 영향이 없습니다.

> Replace only the collector (server) jar with 0.3.1 and restart. No agent redeploy needed. State is
> in-memory (a restart always resumes ingest); no schema change, fully compatible with 0.3.0 databases.

### 주의 | Notes

- 일시정지 중 agent flush 는 503 을 받아 1초 후 1회 재시도 후 해당 batch 를 drop 합니다. **유지보수는 수 분 내로 짧게 끝내고 즉시 재개**하세요 — 일시정지가 길수록 drop 되는 데이터가 늘어납니다(30분 cap 이 무한 drop 은 막습니다).
