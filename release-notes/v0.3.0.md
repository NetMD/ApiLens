## ApiLens v0.3.0 — API Key 인증 + 마스킹 ReDoS 가드 + 온라인 VACUUM | API Key auth, ReDoS guard, online VACUUM

v0.3 첫 릴리스입니다. 관리·조회 API 에 **선택적 API Key 인증**, 마스킹 룰 저장 시 **ReDoS 가드**,
데이터를 지우지 않고 파일 크기를 줄이는 **온라인 디스크 최적화(VACUUM)** 를 추가했습니다.
**server 와 UI 만 바뀌고 agent 모듈은 변경 없음** (v0.1/v0.2 agent 그대로 호환), 스키마 변경 0.

First v0.3 release: optional **API Key authentication** for management/query APIs, a **ReDoS guard** when
saving masking rules, and **online disk optimization (VACUUM)**. Server and UI only — the agent is unchanged.

---

### ⚠️ 주의 (BREAKING) | Breaking

- **관리/조회 API 에 선택적 API Key 인증이 신설됐습니다.** `APILENS_AUTH_API_KEY` 환경변수(또는 `-Dapilens.auth.api-key`)로 토큰을 설정하면, 그 시점부터 `/v1/**` 관리·조회 API 는 `Authorization: Bearer <토큰>` 헤더를 요구합니다(없거나 틀리면 401).
  - **업그레이드**: jar 만 0.3.0 으로 교체·재기동. **토큰 미설정 시 0.2.x 와 동일하게 무인증**으로 동작하고 기동 경고를 1회 남깁니다 — 기존 환경이 깨지지 않습니다.
  - **롤백**: 0.2.x jar 로 되돌려도 DB 호환(스키마 무변경).
  - **agent 영향 0**: agent 적재 경로 `POST /v1/spans` 는 인증 면제 — 토큰을 켜도 원격 agent 적재는 끊기지 않습니다.

### 새로운 기능 | What's new

- **API Key 인증** — Spring Security 없이 경량 서블릿 필터로 단일 토큰을 상수 시간 비교(`MessageDigest.isEqual`)로 검증합니다. 면제 경로: setup wizard · agent 적재(`/v1/spans`) · 헬스체크 · 정적 자산/SPA. 토큰은 server 기동 옵션으로만 두며 DB 에 저장하지 않습니다.
- **인증 토큰 입력 UI** — 설정 페이지에서 토큰을 입력하면 브라우저 세션에 보관하고 이후 요청에 헤더로 붙입니다. 401 이 반복되면 자동 새로고침을 멈추고 토큰 입력을 유도합니다.
- **마스킹 정규식 ReDoS 가드** — custom 룰 저장 직전, 제한 시간(100ms) 안에 시험 매칭이 끝나는지 검사하고 catastrophic backtracking 이 의심되면 400 `pattern is too complex` 로 거부합니다(별도 스레드 없이 경과 시간 자가 검사).
- **온라인 디스크 최적화(VACUUM)** (`POST /v1/maintenance/optimize`) — 데이터를 지우지 않고 SQLite `VACUUM` 으로 빈 공간을 회수해 DB 파일 크기를 줄입니다. 파일을 삭제/재생성하지 않고 같은 파일을 내부 재구성합니다.

### 주의 (남은 한계 — 신뢰 네트워크 전제) | Notes

- **agent 적재(`/v1/spans`)는 무인증** — agent 무변경을 위한 선택. 망 격리/방화벽이 유일한 방어입니다.
- **토큰이 평문(HTTP)으로 전송** — v0.3 은 TLS 미내장. 운영망/방화벽 격리에서만 쓰고, 필요하면 리버스 프록시로 TLS 종단하세요. 공용망 직접 노출 금지.
- **ReDoS 가드는 신규 룰 저장 시점만 검사** — 이미 저장된 룰·적재 마스킹 핫패스는 대상이 아니며, 근본 차단(linear-time 매칭)은 다음 agent 라운드로 이월됐습니다.
