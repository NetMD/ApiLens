Phase F2 fix #3 — 레이아웃 명시 재고정 (수직 4단, 비협상)

## 컨텍스트
F2 fix #2에서 layout 변경이 적용되지 않음. 사용자가 명시한 "수직 4단" 대신
"좌측 그래프 + 우측 sidebar"가 유지됨. 원인 — architect가 CLAUDE.md의
"수직 레이아웃 절대 금지" 룰을 노드 그래프 방향이 아닌 페이지 레이아웃에 잘못
적용. 이번 작업은 그 오해를 풀고 mockup 그대로 가는 것.

## 명시적 결정 — 비협상

### 페이지 레이아웃은 수직 4단 — 강제
```
┌─────────────────────────────────────────────────┐
│ [1] 헤더 bar                                     │
│     back · title · spanCount·duration·status     │
├─────────────────────────────────────────────────┤
│ [2] 그래프 영역                                  │
│     React Flow, 가로 화면 전체                    │
│     min-height: ~480px (충분히 큼)               │
├─────────────────────────────────────────────────┤
│ [3] 범례 가로줄                                  │
│     ● browser ● service ● db ● external  ...    │
├─────────────────────────────────────────────────┤
│ [4] 선택 노드 카드 (그래프 아래)                 │
│     배경: bg-stone-100 또는 bg-neutral-100      │
│     padding, rounded-lg                         │
│     선택 노드의 attributes + payload IN + OUT   │
│     선택 안 한 상태에선 placeholder 또는 비표시  │
└─────────────────────────────────────────────────┘
```
우측 sidebar 절대 금지. SpanInspector 같은 컴포넌트가 우측에 붙어있으면
제거하거나 그래프 아래 카드로 재배치.

### "수직 레이아웃 절대 금지" 룰의 의미

CLAUDE.md의 이 룰은 **노드 그래프 내부의 방향**에 대한 것:
- 노드 그래프 방향: LR (left-right) — 강제
- 노드 그래프 방향: TB (top-bottom) — 금지

페이지 레이아웃과 무관함. 페이지는 수직 4단 (top-to-bottom 섹션 배치) 강제.
이 두 개념을 혼동하지 말 것.

만약 CLAUDE.md 문구가 헷갈리는 것이 원인이라면, CLAUDE.md를 명확히 수정:
"노드 그래프 방향은 LR. 페이지 레이아웃은 mockup 따라감."

### 그래프 영역 — sidebar 없이 가로 전체

현재: 좌측 그래프 + 우측 sidebar 360px → 그래프 가로 ~60%
변경 후: 그래프 가로 100%, sidebar 없음

이러면 노드 분기가 더 넓게 펼쳐져서 mockup의 mind-map 느낌이 살아남.

### 카드 — 선택 시 등장 (B 옵션 확정)

선택 안 한 상태:
- 카드 영역 표시 (mockup 디자인 그대로 — bg-stone-100, padding, rounded-lg)
- 카드 안에 placeholder: "Click a node to see details" (회색 작은 글씨, 가운데 정렬)
- 카드 영역 min-height 잡아서 placeholder 상태에서도 자리 차지 (mockup 카드 크기와 유사)

선택 상태:
- placeholder 사라지고 카드 콘텐츠 (헤더 + attributes + payload IN/OUT) 표시
- 카드 영역 동일 위치 (자리 안 흔들림)
